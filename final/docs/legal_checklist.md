# Правовой чек-лист (12 пунктов)

1. **Источники**: scrapethissite.com (учебный sandbox) + restcountries.com (MPL-2.0).
2. **Цель**: учебный исследовательский проект, не коммерция.
3. **ToS**: scrapethissite.com создан для обучения; REST Countries — публичный API.
4. **robots.txt**: scrapethissite.com не ограничивает; REST Countries API не запрещает.
5. **Авторизация**: Bearer-токен для API (не ПДн), для HTML не требуется.
6. **Обход защиты**: отсутствует.
7. **Объём и частота**: 1 HTML-страница + 4 API-запроса с задержкой 0.5с.
8. **Персональные данные**: не собираются (страны, валюты, языки — не ПДн).
9. **Основание обработки**: общедоступные данные, учебная цель.
10. **Место и срок хранения**: локально, в рамках курса.
11. **Контакт**: указан в User-Agent.
12. **Действия при претензии**: удалить данные, прекратить сбор, задокументировать.
